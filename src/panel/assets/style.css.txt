/*
 * free-llm-router 管理面板样式 —— v0.4 设计系统
 *
 * 结构：
 *   1. 设计令牌（深色默认 / 显式浅色 / 跟随系统的浅色）
 *   2. 基础元素（排版、表单、按钮）
 *   3. 外壳（顶栏、分段导航、主容器、页头、面板）
 *   4. 各视图组件（供应商、任务、用量、API Key、模型、配置、日志）
 *   5. 弹窗、提示、登录页
 *   6. 响应式断点与动效降级
 *
 * 约定：
 *   · 颜色一律走令牌，组件规则里不写死色值 —— 换主题只换令牌；
 *   · 浅色有两套入口（`html[data-theme='light']` 与 `html:not([data-theme])` + 媒体查询），
 *     两处必须同步维护，否则「跟随系统」模式会漏；
 *   · 每个 grid/flex 容器的子元素都要能收缩（min-width: 0），否则长串会撑破手机屏幕。
 */
